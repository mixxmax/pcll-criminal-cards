# 03 Question2（考试 Q2 答题引擎层）

> **定位**：与 `00 Master`、`01 Institutions`、`02 Documents` 平级。前三层按制度和文书整理知识；本层按**考试题型**组织，把历年官方讲评归纳成可直接套用的穷举表和文书模板。规则细节仍以 01 母题卡为主承重，本层只引用、不另立第二套规则。

| 卡 | 用途 | 主要依据 |
|---|---|---|
| EX01 Appeal Grounds - Exhaustive Matrix | Q2 上诉理由的三层穷举（环节 → 事实类型 → 错误方式）：每行含考场可写的规则、往届发生了什么、上诉落点、应用要点；通用 IRAC 插槽；定级规律与写法；保护行动衔接表；程序步骤；逐卷覆盖表与分值；Melvin 案逐段扫描 | LGS10、LGS12、LGS13、LGS14、POST LGS15 复习幻灯片、四份讲评录音转写、Specimen Directions 2025 |
| EX02 Exam Document - Memo to Supervising Partner | Q2 备忘录：文书类型核查、评分结构、结构、段落模式、定级措辞、Part 2 清单、应当／不应当、可插拔模板（六个插口，从 EX01 取材）、自检清单 | LGS12 范例、历年讲评 |

**往届 Q2 只有备忘录一种文书**（EX02 §1 逐卷核查）；Q1 的 Notice of Objection 见 D05。

**上下游**：母题规则 → 16 上诉卡、15 量刑卡；文书卡 → D07 Memorandum to Partner。本层发现的规则缺口登记在各卡 open 块，核实后按"SG 答案 → 凝结卡 → Master"方向回写母题卡。
